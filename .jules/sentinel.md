## 2024-11-08 - SSRF Vulnerability via Redirects in Citation Service
**Vulnerability:** Server-Side Request Forgery (SSRF) risk in `services/citation.py`. The `_is_safe_public_host` check is only performed on the initial URL, but the `httpx.AsyncClient` is configured with `follow_redirects=True`. A malicious external server could redirect the request to an internal IP or local loopback (e.g. `127.0.0.1`, `169.254.169.254`), bypassing the check and potentially accessing sensitive internal services. This is explicitly noted in a comment as a "known residual gap".
**Learning:** `httpx.AsyncClient` follows redirects automatically when `follow_redirects=True`. Pre-flight checks on the initial URL are insufficient. To fully prevent SSRF, every redirected host must also be validated.
**Prevention:** Use an event hook on the client or request to intercept and validate the host before every request, including those spawned by redirects. In `httpx`, this can be done via `event_hooks={'request': [my_hook]}`.
